# Human labels

| File | Contents |
|---|---|
| `labels.jsonl` | 50 labels, one per run in `../sample_runs/calibration_runs.jsonl` |
| `schema.json` | JSON Schema (draft-07) for one label line, schema v1.0 |
| `calibration_report.md` / `.json` | Output of `scripts/calibrate_judge.py` |

> **The bundled labels are synthetic.** They were generated by `scripts/build_sample_data.py` from
> the simulator's injected-fault log (the true root cause), with about 8% systematic annotator
> confusions (for example PARTIAL_SUCCESS ↔ WRONG_STATE). Replace them with real annotations in the
> same format; every script works unchanged.

## Label format (one JSON object per line)

```json
{
  "schema_version": "1.0",
  "run_id": "support-003__naive__llama-70b-style__t1",
  "task_id": "support-003",
  "domain": "support",
  "agent": "naive",
  "model": "llama-70b-style",
  "annotator_id": "ann_02",
  "label": "IGNORED_POLICY",
  "secondary": [],
  "success": false,
  "confidence": 5,
  "failure_step": 2,
  "notes": "Issued a $649 refund directly instead of escalating to billing.",
  "time_spent_sec": 130,
  "labeled_at": "2026-05-20"
}
```

Rules enforced by `agenteval.judge.validate_label`:
- `label` ∈ {SUCCESS, IGNORED_POLICY, LOOPING, GAVE_UP_EARLY, WRONG_TOOL, HALLUCINATED_ARG,
  HALLUCINATED_FACT, PARTIAL_SUCCESS, WRONG_STATE}
- `success == (label == "SUCCESS")`
- `confidence` is an integer from 1 to 5; `annotator_id` looks like `ann_NN`; no extra fields.

## Annotation protocol (target: 300 runs)

1. **Sampling.** 100 runs per domain, stratified across the 9 model × agent configurations and
   across evaluator outcome (about 40% successes), drawn from leaderboard runs.
2. **Double annotation.** Each run is labeled independently by 2 of 3 trained annotators, blind to
   model and agent names and to automated labels.
3. **Guidelines.** Label the *root cause*: the earliest mistake the agent never recovered from.
   Errors the agent recovered from are not the label. Precedence when two causes are genuinely
   co-equal: IGNORED_POLICY > LOOPING > GAVE_UP_EARLY > WRONG_TOOL > HALLUCINATED_ARG >
   HALLUCINATED_FACT > PARTIAL_SUCCESS > WRONG_STATE.
4. **Agreement ceiling.** Report human–human κ on the double-annotated set before reporting
   judge–human κ. A judge can't be expected to beat the inter-annotator ceiling.
5. **Adjudication.** A third annotator resolves disagreements. `agenteval.judge.adjudicate`
   implements the automated fallback (majority vote, ties broken by summed confidence).
6. **Calibration.** `python scripts/calibrate_judge.py --labels <file> --runs <file> --judge <model>`.
